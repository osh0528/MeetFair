# 프로젝트 범위

## 1차 목표

- 회원가입과 로그인
- 약속 생성과 초대
- 참가자별 출발지 입력
- 이동시간 편차가 작은 장소 추천
- 앱 실행 중 실시간 위치 공유
- 약속 30분 전 알림
- 횟수 제한이 적용된 찌르기

## 추가 목표

- 백그라운드 위치 공유
- 준비 인증 카메라
- 예상 도착 시간과 지각 가능성
- 주변 카페와 편의시설 추천

## 개인정보 원칙

- 위치와 카메라는 명확한 동의를 받은 후 사용합니다.
- 약속 참가자에게만 위치를 공유합니다.
- 약속 종료 후 최신 위치를 제거합니다.
- 위치 이력을 기본적으로 영구 저장하지 않습니다.
- 찌르기는 사용자가 허용한 알림 설정을 따릅니다.
